# CLAUDE.md — TimeTracker

Контекст проекта для Claude Code. Читать перед любыми изменениями.

## О проекте
Личный трекер времени для одного пользователя. Два клиента: web/PWA и нативный Android (Kotlin).
Данные только локально, бэкенда нет, деплоя нет. Офлайн обязателен. Интерфейс на русском.

## Модель данных
Проект → Задача (необязательна) → Запись времени (начало, конец, заметка).
Одновременно активен один таймер.
Формат экспорта/импорта JSON должен быть общим для web и Android — это единственный способ переноса данных.

## Стек
- **Web/PWA** (`web/`): React, Vite, TypeScript, IndexedDB (Dexie), Recharts, vite-plugin-pwa. Чистый CSS.
- **Android** (`android/`): Kotlin, Jetpack Compose, Room (SQLite).
- Бэкенд, PostgreSQL, аккаунты, синхронизация — не используем.

## Порядок работ
Сначала web/PWA, затем Android. Список MVP-фич и идей — в `README.md`.

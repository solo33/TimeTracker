# TimeTracker

Личный трекер времени для одного пользователя: **сайт + PWA** и **нативное Android-приложение на Kotlin**.
Все данные хранятся **локально** на устройстве, бэкенда и деплоя нет, работает офлайн. Интерфейс — на русском.

## Требования

- Один пользователь, без аккаунтов и подписки.
- Учёт времени: таймер старт/стоп и ручной ввод записей.
- Иерархия: проект → задача → запись времени. Задача необязательна.
- Все отчёты (счета клиентам не нужны).
- Офлайн обязателен, данные только локально, синхронизации между устройствами нет.
- Перенос данных между web и Android — экспорт/импорт JSON.
- Язык интерфейса: русский.

## Стек

| Часть | Технологии |
|---|---|
| Web + PWA | React, Vite, TypeScript, IndexedDB (Dexie), Recharts, vite-plugin-pwa |
| Android | Kotlin, Jetpack Compose, Room (SQLite) |
| Бэкенд | нет |

## Структура репозитория (план)

```
web/       # сайт + PWA

docs/      # требования, модель данных, формат экспорта
```

## Фичи

### MVP
- Таймер старт/стоп, один активный таймер одновременно.
- Ручное добавление и редактирование записей.
- Проекты (название, цвет, архивация) и необязательные задачи внутри проекта.
- Журнал записей по дням.
- Отчёты за день, неделю, месяц и произвольный период: по проектам и задачам, столбчатые и круговые диаграммы.
- Экспорт в CSV и JSON, импорт из JSON.
- Офлайн-работа, установка PWA, русский интерфейс.

### Возможные дополнения
- Теги и заметки к записям.
- Быстрый запуск последней задачи.
- Уведомление в шторке Android с идущим таймером и виджет.
- Напоминания: «забыли включить таймер», «таймер идёт слишком долго».
- Помодоро-режим.
- Цели: часы в день или неделю на проект.
- Календарный вид недели.
- Оплачиваемое / неоплачиваемое время, ставка в час, подсчёт заработка.
- Импорт из Toggl и Clockify.
- Тёмная тема.
- Резервная копия в файл по расписанию.
- PIN-код или биометрия на Android.
- Позже: синхронизация через облако, мультиязычность.

## Порядок работ

1. Web/PWA: модель данных, таймер, записи, отчёты, экспорт/импорт.
2. Android: та же модель данных и формат экспорта, совместимый с web.

## Статус

Web/PWA: MVP готов (`web/`) — таймер, записи, проекты и задачи, журнал, отчёты, экспорт/импорт, офлайн.
Android: не начат. Формат обмена данными — `docs/export-format.md`.

### Запуск web

```
cd web
npm install
npm run dev      # разработка
npm test         # тесты логики
npm run build && npm run preview   # продакшн-сборка с PWA
```

Из «Возможных дополнений» сделаны только заметки к записям и тёмная тема (по системной настройке).
